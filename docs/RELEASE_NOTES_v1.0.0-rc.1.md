# Agentic Project Lifecycle v1.0.0-rc.1

This release candidate is the first public Codex plugin package of the stable Large Project Skills Suite `1.0.0`.

## Included

- One lifecycle orchestrator and six specialist skills.
- Codex plugin manifest and repository marketplace metadata.
- English and Russian installation and usage documentation.
- Deterministic ZIP and `tar.gz` release archives with SHA-256 checksums.
- Held-out routing evaluation, executable fixture trials, pinned read-only public-repository trials, trace analysis, and instruction ablation evidence.
- CI validation for the suite, plugin publication contract, tests, and release build.

## Release-candidate scope

The behavioral suite is stable. The plugin remains an RC until installation from the tagged public marketplace and cross-environment discovery have been confirmed. No hosted service, authentication flow, or data collection is included.

## Verification

Verify downloaded files against `SHA256SUMS`. The release also includes `promotion-gate.json` and a generated `validation-report.md` tied to the release commit.

Known limitations are documented in `STABILITY_REPORT.md`, `VALIDATION.md`, and `evals/README.md`.
