# Privacy policy

Last updated: 2026-07-21

Agentic Project Lifecycle is a local, skills-only plugin. The plugin itself does not operate a server, create user accounts, collect analytics, set cookies, or send project data to the maintainer.

The plugin provides instructions, templates, and local Python scripts. Information processed by Codex, GitHub, an operating system, or any user-enabled connector is governed by those products and by the user's configuration. Users should review the privacy terms and data controls of every external service they enable.

Do not include secrets, personal data, or confidential material in public issues, pull requests, evaluation fixtures, or logs. Questions about this policy may be raised through the repository's GitHub issue tracker without including sensitive information.
