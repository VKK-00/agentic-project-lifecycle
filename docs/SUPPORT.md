# Support

Use [GitHub Issues](https://github.com/VKK-00/agentic-project-lifecycle/issues) for reproducible bugs, installation problems, documentation gaps, and focused feature requests.

Before filing an issue:

1. Confirm that the problem occurs with the newest published release.
2. Run `python scripts/validate_publication.py` when working from a clone.
3. Include the Codex version, operating system, plugin version, exact command or prompt, expected behavior, actual behavior, and a minimal reproduction.
4. Remove secrets, personal data, private repository content, and machine-specific credentials.

Security issues must be reported privately as described in [SECURITY.md](../SECURITY.md). There is no guaranteed service-level agreement for general support.
